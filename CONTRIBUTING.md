# Contributing to Vocal-Gen

Thank you for your interest in contributing to Vocal-Gen! ❤️

Vocal-Gen is an open-source text-to-speech web application built with Python and Django. Contributions of all kinds are welcome, including bug fixes, new features, tests, documentation, and UI improvements.

## Getting Started

### 1. Fork the repository

Fork the repository on GitHub and clone your fork:

```bash
git clone https://github.com/NandhuT17/vocal-gen.git
cd vocal-gen
```

### 2. Set up the development environment

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Linux or macOS:

```bash
source .venv/bin/activate
```

On Windows:

```powershell
.venv\Scripts\activate
```

Install the project's dependencies using the instructions in the README.

### 3.  Make and test your changes

- Keep changes focused on one issue.
- Follow the existing code style.
- Update documentation if your changes affect how the application works.
- Never commit passwords, API keys, or other secrets.

### 4. Commit your changes

```bash
git add .
git commit -m "message"
```

Only stage the files relevant to your contribution.

### 5. Push your branch

```bash
git push -u origin fix/short-description
```

Open a pull request from your fork against the main Vocal-Gen repository.

## Pull Request Guidelines

Please include:

- A clear description of the problem and solution.
- Testing steps and results.
- Screenshots for relevant UI changes.

Keep pull requests small and focused whenever possible.


## Questions and Suggestions

If you're unsure about an approach, open an issue to discuss it before implementing a large change.

Thank you for helping make Vocal-Gen better! 🚀
